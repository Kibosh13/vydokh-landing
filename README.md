# Выдох 2.0

Лендинг камерного ретрита с адаптивной вёрсткой, контактной формой и небольшой CRM для организаторов.

## Структура

- `site/` — HTML и графические материалы лендинга.
- `worker/` — серверные маршруты для приёма и обработки заявок.
- `db/` и `drizzle/` — схема и миграции базы D1.
- `scripts/` — сборка, проверки и генерация безопасной статической демоверсии.

## Локальная проверка

```bash
npm install
npm run build
npm run validate
```

Полная версия использует серверный Worker, базу D1 и секрет `ADMIN_PASSWORD`, который задаётся только в окружении хостинга и не хранится в репозитории.

## GitHub Pages

Команда `npm run build:pages` создаёт статическую демоверсию в `.pages-dist/`. В ней доступны дизайн, изображения, адаптивная вёрстка, модальное окно и прямые ссылки Telegram.

GitHub Pages не поддерживает серверную базу и закрытую CRM, поэтому отправка заявок и рабочая админка в демоверсии отключены. Для демоверсии добавлены `noindex`, `nofollow` и запрещающий индексацию `robots.txt`.
